# 🍳 Gemini Recipe Agent

An AI-powered recipe agent built with **Google Gemini** and **Python**. The project uses a recipe database and a Gemini-based agent to understand user requests, reason about recipes, and generate helpful responses.

## 🚀 Features

- 🤖 Powered by Google Gemini
- 🍽️ Recipe database with multiple recipes
- 🔎 Finds suitable recipes based on user requirements
- 🧠 AI-based reasoning and response generation
- ☁️ Runs directly in Google Colab
- 🔐 Uses Colab Secrets for API key management

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Google Colab
- Generative AI
- AI Agents / RAG
